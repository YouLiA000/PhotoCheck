## 口径提醒

- `类别判错` 是「框对上了但 subtype 判错」，既不算漏检也不算误报。
- `误报` 只统计画面上的对象；元数据项按 subtype 在整图范围内配对。
- 本表不含首次漏检：同一套模型看不见的东西，重跑也看不见（见 R-03）。
- 置信区间按**图**重采样（同一张图里的对象不独立），不是按对象。
- `failure_cases.csv` 逐条列出漏检 / 误报 / 类别判错，可直接作为失败案例库的输入。
