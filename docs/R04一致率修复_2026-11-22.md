# R-04 人工与机器一致率修复（2026-11-22）

A 的报告 `A报_R04一致率算反_2026-11-22.md` 属实。修复前，人工变量用
`readable=1`（坏结果），机器变量用 `passed=1`（好结果），却直接比较相等：

```text
30 行 not_readable + 30 行 passed
人工与机器实际一致率 = 100%
旧脚本输出           = 0%
```

## 修复

`tools/finalize_r04_manual.py` 现在先把三方统一为“是否仍有残留”：

```text
human_residual     = manual_consensus == readable
primary_residual   = primary_status != passed
tesseract_residual = tesseract_status != passed
```

再用同极性数组计算一致率。这样代码中的 `==` 不再需要读者反推两个变量的方向。

## 回归

新增 `tools/tests/test_finalize_r04_manual.py`，覆盖：

- 30 行 `not_readable` + 全 `passed` -> 一致率 1.0；
- 30 行 `readable` + 全 `passed` -> 一致率 0.0；
- 人工和机器都判定有残留 -> 1.0；
- 15/15 混合且方向匹配 -> 1.0；
- 空评审值拒绝；
- 两位评审分歧必须有第三人裁决；
- 裁决后接受，并正确计算 0.5 一致率。

## 独立性边界

`manual_review_status=complete_two_independent_reviewers` 只表示两份表单已填满且
取值合法。新增字段：

```json
{
  "manual_independence_source": "process_attestation_only"
}
```

提醒审计方：独立性来自两份隔离表单和评审签名，脚本无法从 CSV 证明两个人确实
独立完成。
