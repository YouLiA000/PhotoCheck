## 口径

- 只测纯 OCR 稳态；冷启动不进入闸门。
- 每图先运行 1 次作废，再运行 3 次并取图内中位数。
- 集合统计单位为“每图中位数”：
  - `median_of_image_medians`
  - `p95_of_image_medians`
  - `max_of_image_medians`
- 正式测量要求接市电；电池结果只作诊断。
- 换图必须升版本并取得三人同意。

## 结论

`T_ocr_ref_v2 = 2690.2 ms` 是 B 验收机在 2026-11-15 的参考测量值，
2026-11-22 起只用于横向报告，不作为跨机绝对闸门（见 `DR-006`）。
后续 dev 验收闸门为：

```text
median_dev / median(T_ref_local) ≤ 1.2
p95_dev    / p95(T_ref_local)    ≤ 1.5
max_dev    不设硬线，超过 2× 时逐图解释
```

旧的 `1686.3 ms` 继续只作历史预验收参考，不能与新参考集数字混用。
