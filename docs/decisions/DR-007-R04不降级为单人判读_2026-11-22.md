# DR-007：R-04 不降级为单人判读

- 日期：2026-11-22
- 状态：通过（B 依据现行规格与 A/C 回函决定）

## 结论

R-04 继续要求两位真实评审独立判读。当前只有 C 的 30 行结果，因此
`R04-01` 保持 PARTIAL；不得把一人填两列、由开发者代填或把单份结果复制成
两份来换取 PASS。

C 的原始答复归档为 `docs/R04_评审C答复_2026-11-22.md`，
机器可读转录为 `docs/R04_评审C_2026-11-22.csv`。这份材料只算一位评审，
不是最终 `manual-summary.json` 的输入。

## 理由

1. 规格卡明确写的是“两人独立判断”，单方结果无法计算评审一致率或 kappa。
2. A 拒绝代填；C 也明确把 R-04 双人判读列为未完成事项。
3. 单人验收会让“独立评审”失去实际含义，属于伪造验收证据，比保持
   PARTIAL 更危险。
4. 如果项目确实要降低要求，必须先修订规格卡、记录风险和责任人，再由 A/C
   书面同意；本次回函中没有这种授权。

## 未采用方案

- 把 C 的结果复制到 A/B 两列：产生虚假一致率。
- 由 B 补填第二列：开发者不是独立评审，且已看过预期结果。
- 直接修改审计判据：只是隐藏缺口，没有降低实际风险。
