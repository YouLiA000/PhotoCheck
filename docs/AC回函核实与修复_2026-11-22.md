## 三、ExifTool 口径

该问题属实：

- `service.py` 曾把 ExifTool 注释成可选；
- `tools/check_env.py` 缺 ExifTool 只报 WARN 且退出 0；
- 多个脚本各自解析路径，借 venv 时找不到项目内副本。

已统一为：

1. `photocheck.core.metadata.find_bundled_exiftool()` 是唯一解析入口；
2. 开发布局查找 `tools/exiftool/exiftool.exe`，便携布局查找
   `runtime/exiftool/exiftool.exe`，环境变量可覆盖；
3. `tools/check_env.py` 缺失、调用失败或版本不是 13.61 时返回失败；
4. 应用自检缺 ExifTool 时返回失败；
5. 离线取证脚本自动注入项目内 ExifTool；
6. `audit_offline.py --run-smoke` 无需手工设置环境变量即可找到项目内副本。

## 四、掩码第二实现

该问题属实。原先 A 引擎自带 `mask_phone` / `mask_idcard`，对短值会暴露过多。

现在：

- 唯一实现为 `photocheck/contract/masking.py`；
- 根 `contract/masking.py` 只做兼容转发；
- A 引擎直接 import canonical 函数，不再定义本地实现；
- 国家码、空格/连字符、短值和身份证末位大写均使用同一套规则；
- 审计会 AST 检查 canonical 之外是否再次定义 `mask_phone` / `mask_idcard`。
