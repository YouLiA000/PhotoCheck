## 二、接口清单与跨仓库导入

### 2.1 `PHOTOCHECK_REPO_ROOT` 的语义

`PHOTOCHECK_REPO_ROOT` 指仓库根目录，即包含 `photocheck/` 的目录，不是 `photocheck/` 包目录。

例如在 B 的机器上可以是：

```text
D:\Desktop\codexTEST\_github_photo_check
```

C 在其他机器上应设置为 C 实际 checkout 的仓库根目录，不能硬编码 B 的盘符。

### 2.2 Manifest 位置

机器可读清单位于仓库根目录下的：

```text
photocheck/interfaces.json
```

契约 Schema 相对仓库根目录的路径为：

```text
photocheck/contract/schema/photocheck-v4.schema.json
```

### 2.3 Manifest 格式

当前格式不是 `"module:function"` 字符串，而是带名称的结构化对象：

```json
{
  "manifest_version": "photocheck/interfaces/v1",
  "package_root": "photocheck",
  "contract_version": "photocheck/v4",
  "entries": {
    "ingest": {
      "module": "photocheck.core.ingest",
      "function": "ingest_image"
    },
    "detect": {
      "module": "photocheck.detectors.a_adapter",
      "function": "analyze_a"
    },
    "probe": {
      "module": "photocheck.detectors.a_adapter",
      "function": "probe_a_region"
    },
    "redact": {
      "module": "photocheck.core.redaction",
      "function": "apply_redactions"
    },
    "plan": {
      "module": "photocheck.contract.workflow",
      "function": "build_redaction_plan"
    },
    "process": {
      "module": "photocheck.core.pipeline",
      "function": "process_and_export"
    },
    "full_recheck": {
      "module": "photocheck.core.full_recheck",
      "function": "full_file_recheck"
    }
  },
  "contract_schema": "photocheck/contract/schema/photocheck-v4.schema.json"
}
```

### 2.4 C 的审计应如何导入

C 的 RD-01 应对应 `entries.redact`，DET-01 应对应 `entries.detect`。

推荐实现：

```python
import importlib
import json
import os
import sys
from pathlib import Path

root_value = os.environ.get("PHOTOCHECK_REPO_ROOT")
if not root_value:
    # RD-01 / DET-01 记为 SKIP
    raise unittest.SkipTest("PHOTOCHECK_REPO_ROOT is not configured")

root = Path(root_value).resolve()
manifest_path = root / "photocheck" / "interfaces.json"
if not manifest_path.is_file():
    raise FileNotFoundError(manifest_path)

manifest = json.loads(manifest_path.read_text(encoding="utf-8"))
if str(root) not in sys.path:
    sys.path.insert(0, str(root))


def resolve(entry_name):
    entry = manifest["entries"][entry_name]
    module = importlib.import_module(entry["module"])
    function = getattr(module, entry["function"])
    if not callable(function):
        raise TypeError(f"{entry_name} is not callable")
    return function


apply_redactions = resolve("redact")
analyze_a = resolve("detect")
```

C 最新同步中给出的这种伪代码不能直接使用：

```python
getattr(importlib.import_module("photocheck"), name)
```

实际验证结果：

```text
analyze_a_top_level=False
apply_redactions_top_level=False
```

原因是 `photocheck/__init__.py` 没有在包级别重新导出这两个函数。必须根据 manifest，从 `entry["module"]` 导入模块，再读取 `entry["function"]`。

### 2.5 审计结果约定

| 条件 | 结果 |
|---|---|
| 未设置 `PHOTOCHECK_REPO_ROOT` | `SKIP` |

### 6.5 C 的调用链

C 应按以下顺序调用：

```python
from photocheck.contract import build_redaction_plan
from photocheck.core import ingest_image, process_and_export
from photocheck.detectors import analyze_a

with ingest_image(path) as ingested:
    envelope = analyze_a(
        ingested.image,
        ingested.descriptor["image_id"],
    )
    detections = [
        *ingested.detections,
        *envelope.detections,
    ]
    decisions = make_user_decisions(detections)
    plan = build_redaction_plan(
        ingested.descriptor,
        detections,
        decisions,
        revision=1,
    )
    result = process_and_export(
        ingested,
        plan,
        output_dir=output_dir,
        detections=detections,
        decisions=decisions,
        run_full_recheck=True,
    )
```

注意：

- `ingested.detections` 当前只有 metadata；
- `envelope.detections` 包含 text、qr、face；
- 两张列表必须合并后统一生成 Decision；
- `image_id` 必须由 `ingested.descriptor` 传给 A；
- C 不能再次从原文件读图并自行矫正，否则旋转图坐标会偏移。

### 6.6 手动补框

```python

    "method": "solid",

```

规则：

- `bbox` 使用 EXIF 方向矫正后的工作图像素坐标；
- 默认方法为 `solid`；
- 二维码区域强制 `solid`；
- 手动框不伪造为 Detection；
- 最终仍要进入同样的复检流程。
