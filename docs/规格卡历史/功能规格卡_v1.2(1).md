### 0.2 共享契约 v2（三人共同遵守，改动需三人同意）

**Finding（所有检测器的统一返回）**

~~~json
{
  "id": "f-001",
  "kind": "meta | text | qr | face",
  "subtype": "见下方枚举",
  "bbox": [x, y, w, h],
  "score": 0.93,
  "text_ref": "仅内存持有，不落盘",
  "payload_ref": "仅内存持有，不落盘",
  "decodable": true,
  "risk": 1,
  "default_action": "hide",
  "selected": true,
  "action": "hide",
  "verify_status": "pass"
}
~~~

| 字段 | 规则 |
|---|---|
| bbox | **EXIF 方向矫正后的工作图坐标系**（不是手机原图坐标系）；kind=meta 时为 null |
| score | 0~1；meta 类固定 1.0 |
| text_ref / payload_ref | **只允许存在于内存**；写日志、写历史、写报告时一律替换为掩码版本（如 138****0000） |
| decodable | **仅 qr 类有值**：true / false；其余为 null。解不出时为 false，**但仍必须给出 bbox** |
| risk | 1 / 2 / 3 |
| selected | 用户是否勾选处理（默认 true，用户可取消） |
| action | hide / keep / skip（keep = 用户明确保留） |
| verify_status | not_checked / pass / fail / na（na = 未勾选处理，不参与判定） |

**subtype 枚举（封闭列表，新增需三人同意）**

| kind | 允许值 |
|---|---|
| meta | gps, datetime, device, serial, thumbnail, software |
| text | phone, idcard, tracking, doorplate（基础）；address, studentid, bankcard, plate, email（附加） |
| qr | qr_wechat_card, qr_wechat_group, qr_wechat_pay, qr_alipay, qr_wifi, qr_vcard, qr_contact, qr_geo, qr_code, qr_link, qr_unknown |
| face | face_region |

**Verdict（复检器返回，两个结论分开）**

~~~json
{
  "disposal_ok": true,
  "residual_risks": [],
  "checks": [
    {"name": "exif", "scope": "selected", "ok": true,  "method": "exiftool + piexif"},
    {"name": "qr",   "scope": "selected", "ok": true,  "method": "pyzbar 重解码"},
    {"name": "ocr",  "scope": "selected", "ok": false, "method": "同 OCR 复跑"},
    {"name": "face", "scope": "selected", "ok": true,  "method": "mediapipe 复跑"}
  ],
  "disclosure": "未检出可识别的敏感文字（基于同一 OCR 检测器，不代表图像绝对不可读）"
}
~~~

| 字段 | 含义 |
|---|---|
| disposal_ok | **处置有效性**：只对 selected=true 的对象判定，全部处理干净才为 true；无任何处理后对象时为 null（不算失败） |
| residual_risks | **全图残余提示**：包含用户主动保留（action=keep）的项，只做提示，**不影响 disposal_ok** |
| disclosure | 固定话术，必须带检测器限定语 |

> 两句话必须分清：**「你勾选处理的东西处理干净了没有」**（disposal_ok）与 **「这张图现在还危险吗」**（residual_risks）。混成一个布尔值，就是 v1.1 最大的逻辑漏洞。

### 0.4 Definition of Done（所有卡通用）

- [ ] 在 main 分支，别人 git clone 后按 README 能跑
- [ ] ≥3 条自动化测试或固定测试图
- [ ] 在**别人的电脑**上跑通过一次
- [ ] 异常输入不崩溃（空图、超小图、非图片文件、无 EXIF 的 PNG）
- [ ] README 有 3 行使用说明
- [ ] **不新增网络调用**（见 K-14 审计方法）

### 0.5 隐私与措辞红线（v1.2 新增，全部卡适用）

1. **原始 text / payload 永不落盘**。日志、历史、报告只存掩码。
2. **报告与面板默认只放脱敏后的图**，不放原图缩略图（原图缩略图 = 把隐私写进报告）。
3. **不做安全承诺**。禁用"已确保安全""可以放心分享""发给熟人问题不大"。只陈述事实：「未检出……（基于 X 检测器）」。
4. **不给社交建议**。工具不判断"该不该发""发给谁"，只列风险项，由用户决定。
5. **演示一律用虚构样本**（自打印假证、自写假单号、自己生成的二维码），不使用他人真实信息。
6. **不做人脸识别**，不引入 embedding 模型。

### K-08 区域处置

| 项 | 内容 |
|---|---|
| 负责人 | **B** |
| 人日 | 2.0 |
| 周次 | W6–W7 |
| 依赖 | K-01, K-03, K-05, K-07 |

**输入**：image + selected 的 Finding
**输出**：脱敏后的 image（交 K-02 导出）

**工具**

| 环节 | 工具 | 用法 |
|---|---|---|
| 裁剪 | NumPy 切片 | 按 bbox 取 ROI |
| 模糊 | cv2.GaussianBlur | **核 = 区域短边 / 4，动态计算** |
| 马赛克 | cv2.resize + INTER_NEAREST | 先缩到 1/20 再放大 |
| 纯色 | NumPy 填充 | 默认黑 |
| 外扩 | 自写 | **base 4px + 短边 3%，且 clamp 在图内**（不写死 6px） |
| 边界处理 | 自写 | 邻接图像边缘时只扩到边界，不裁到负坐标 |

**关键规则**

1. **二维码一律实心遮盖**（纯色矩形），不允许模糊或马赛克——QR 有纠错能力，半遮可能仍可解。
2. 模糊核随区域尺寸动态计算，不写死。
3. 一律在像素上重算后走 K-02 重建导出。

**验收标准**

- [ ] 三种方式可用，不破坏其他区域
- [ ] 遮住的文字重跑 OCR 读不出原文（开发集 ≥9/10）
- [ ] **遮住的二维码重跑解码，成功率为 0**（实心遮盖，要求 100%）
- [ ] 4K 图处理 < 1s
- [ ] 贴边区域不报错（构造一张 bbox 落在角落的测试）

**降级**：马赛克不达标 → 只留模糊 + 纯色。

| 人日 | 2.5 |
| 周次 | **W2 起分四次增量，W8 汇总** |
| 依赖 | 按增量逐步接入 |

> **v1.2 最大改动**：复检器不再等到 W8 一次性开发，而是**跟着检测器一起长**。早做半个月，返工少一半。

**增量排期**

| 阶段 | 周次 | 接入什么 | 产出 |
|---|---|---|---|
| 9a | W2 | EXIF 检查（exiftool） | 能判"元数据是否清干净" |
| 9b | W4 | OCR 复检 | 能判"文字是否还读得出" |
| 9c | W5 | 二维码复检 | 能判"码是否还可解" |
| 9d | W6–W8 | 人脸复检 + 汇总成 Verdict | 完整四检 |

**核心逻辑（两条独立结论）**

~~~text
对每个 selected=true 的 Finding：
    verify_status = 用独立代码路径重新检测该区域/该类型
    pass  -> 计入通过
    fail  -> disposal_ok = false，进 residual_risks

对 action=keep 的 Finding：
    -> 只进 residual_risks（提示），不参与 disposal_ok

若没有任何 selected=true 的 Finding：
    -> disposal_ok = null（不算失败）
~~~

**工具**

| 检查 | 工具 | 方法 |
|---|---|---|
| EXIF | ExifTool + piexif | 独立进程重新读文件 |
| 二维码 | pyzbar 重跑 | 对已遮区域解码 |
| 文字 | RapidOCR 重跑 | 对已遮区域 OCR |
| 人脸 | mediapipe 重跑 | 仅对 selected 的人脸区域 |
| 结构 | Pillow | 尺寸、可打开、非全黑 |

**关键设计原则**

1. 复检必须走**独立代码路径**，不复用处置时的中间变量。
2. 只报事实，不做承诺；disclosure 固定话术带检测器限定语。
3. **用户保留的东西不算失败**，只做提示。

**验收标准（v1.2 重写）**

- [ ] 含「已勾选处理但未处理」的图 → **disposal_ok = false**
- [ ] 干净负样本（无任何风险）→ **不报错、不误判失败**，disposal_ok = null
- [ ] 用户全部保留 → disposal_ok = null，residual_risks 有内容
- [ ] 只遮二维码一半的图 → **必须 fail**（这条最能体现价值）
- [ ] 正确处理的图 → disposal_ok = true
- [ ] 四项 check 能单独显示，不是一个笼统的通过
- [ ] 复检耗时 ≤ 处理耗时的 2 倍（以实测为基准）

**降级**：OCR 复检太慢 → 只对 selected 区域做局部复检。
