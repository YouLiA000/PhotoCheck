## 1. 数据变更（会影响你的读取，必须同步）

### 1.1 `orientation` 统一为 `exif_transposed`

| 项 | 迁移前 | 迁移后 |
|---|---|---|
| dev 真值 | 35 份 `as_stored` | 35 份 `exif_transposed` |
| lock 真值 | 23 份 `as_stored` | 23 份 `exif_transposed` |

**为什么改**：DR-002 裁定采用规格卡示例值 `exif_transposed`，与 A 的检测器输出一致。
**对你的影响**：
- 如果 B 侧有代码按 `orientation == "as_stored"` 分支，现在会走不到；
- 载入层（K-01）按 EXIF 转置后应写 `exif_transposed`，这是正确的；
- 这两套数据本身没有 EXIF orientation tag，所以像素坐标不受影响（转置是恒等），
  但**字段值必须统一**，否则比对时会误判"坐标系不一致"。

### 1.2 qr 的 details 改用 typed 字段

| subtype | 迁移前 | 迁移后 |
|---|---|---|
| `qr_link` | `{decodable, masked_summary: "qr/qr_link"}` | `{decodable, safe_domain: "example.com"}` |
| `qr_wifi` | `{decodable, masked_summary: "qr/qr_wifi"}` | `{decodable, safe_ssid: "Office-5G"}` |
| `qr_vcard` / `qr_wechat_pay` / `qr_unknown` | `masked_summary` | 只留 `decodable` |

**为什么**：K-06 要求界面能显示"扫码落到哪个网站 / 连哪个 Wi-Fi"，通用摘要做不到。
schema 里的 `masked_summary` / `domain` / `ssid` 标着"**W7 前移除**"的过渡别名，现在已无真值在用。

**对你的影响**：
- 读 qr 的 details 时不要再取 `masked_summary`；
- 写 qr 记录时按 subtype 给 `safe_domain` 或 `safe_ssid`，没有域名的就不给；
- 校验器会拒绝把整个 `WIFI:S:xxx;P:yyy;;` payload 塞进 `safe_ssid`（已有回归测试）。

# 1. 用 A 的 analyze 过 dev 集，每图输出一个 Detection[] 到 preds/

## 3. 接口现状（与你的 K-09 对接）

| 接口 | 签名 | 状态 |
|---|---|---|
| `analyze(image, image_id, cfg, store, kinds)` | → `AnalysisResult`（`.detections` / `.warnings` / `.timings_ms`） | ✅ 可用，输出过契约 |
| `probe_region(image_or_path, bbox, ...)` | → `RegionProbe`（区域内"还检出什么"） | ✅ 可用，收路径 / PIL / ndarray |
| `detector_status()` | → `{"ocr": "ok", "qr": "ok", "face": "unavailable", "qr_backend": "pyzbar"}` | ⚠️ face 不可用，见下 |

### 3.1 你需要知道的三个前提

1. **检测器是纯函数**，`f(image, roi=None)`，没有跨调用状态——K-09b/K-09c 可以对已遮区域独立重跑。
2. **`probe_region` 给的是"区域内还检出什么"，不是 passed/failed**。判定逻辑在 B 的 K-09，
   检测侧不改变结论。
3. **二维码必须扩静区再解码**（A 的 BC-0007）。按 Detection.bbox 紧贴裁切会把静区切掉，
   实测"全图能解、按框裁就解不出"。A 已在 `detect_qr()` 内部处理，你不要在外面再裁一次。

### 3.2 `face` 恒不可用（不阻塞你）

C 的环境是 mediapipe **0.10.35**，A 要求 **0.10.14**，所以 `face` 永远返回 `unavailable`。

- K-09d 请按 `pending` 处理，**不要**把它当成"该区域没有人脸"；
- C 的合成集没有任何人脸样本（无合规来源），K-07 维持 P1 不阻塞；
- 如果之后要评人脸，C 会把 mediapipe 降到 0.10.14。
