## 四、空目录复现

1. 将 ZIP 完整解压到空目录。
2. 不安装 Python、ExifTool 或其他依赖。
3. 双击 `Check.bat` / `自检.bat`。
4. 确认三个检测器、ExifTool 和端到端示例均通过。
5. 双击 `Start.bat` / `启动.bat`。
6. 上传一张图片，检测、选择、处置、复检、导出并下载报告。
7. 确认原图哈希不变、导出图不含原图元数据。

本次已在独立解压目录完成步骤 1–6 的自动自检，结果为
`端到端通过：检测 3 项，处置 3 个区域，复检状态 passed`。

## 五、已知限制

- 评测主要基于合成 dev 集，不能直接外推到所有实拍场景。
- `passed` 只表示当前检测手段未发现残留，不代表绝对安全。
- K-07 人脸检测只提供区域提示，不做身份识别。
- 姓名、地址、邮箱等 S-7 扩展类型不在本轮核心验收范围。
- 产品演示录像由用户明确延期，暂不作为本次候选包的门禁；不得把 K-14
  断网取证录像标记为产品演示。

## 六、发布门禁

在打 `v1.0-demo` tag 前仍需：

1. 本发布准备分支通过协作者审核；
2. 最终 ZIP 的 SHA-256 与 `BUILD_INFO.json` 已归档；
3. 从 ZIP 独立解压复跑通过；
4. Release 资产上传成功；
5. 产品演示录像按用户决定标记为“延期”，不得写成“已完成”。
