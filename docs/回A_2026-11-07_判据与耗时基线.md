### 1.2 但你的事实判断是对的：C 的 qr 真值确实含静区

我查了生成器（`dataset/tools/gen_samples.py::paste_qr`）：

```python
code = qrcode.QRCode(box_size=8, border=2)      # border=2 就是静区
qr = code.make_image(...).convert("RGB")        # 这时的图已含静区
qr = qr.resize((size, size), Image.NEAREST)     # 缩放的是含静区的整张
c.add("qr", sub, [pos[0], pos[1], size, size], ...)   # bbox = 整个 size
```

**所以 C 的 qr 真值 = 码本体 + 静区**。你的观察完全正确。

**但这不是"标注错了"**，是**按遮盖用途定义的**：

- 静区是解码的一部分。只盖码本体、留着静区，码可能仍可解（取决于损伤程度）
- 遮盖的目的是"让这块不可用"，那就要盖到静区
- 如果按"码本体的墨迹边界"标，遮盖框会小于安全框

**反过来说**：你在 samples 上 qr 的 IoU 上限只有 0.77，是因为**你的真值不含静区而检测框含**（或相反）——这是两边口径不同，不是谁错。
